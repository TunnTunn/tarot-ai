# Issue tracker — GitHub Issues (repo `tarot-ai`)

- Issues sống trên GitHub Issues của repo public `tarot-ai`.
- Tạo issue: `gh issue create --title "..." --label ready-for-agent --body "..."`.
- Ticket agent-ready gắn label `ready-for-agent`.
- Label triage mặc định: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`.
